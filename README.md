# Sauti Studio: downloads

Sauti Studio is a voice editor for journalists, for Windows 10 or later and macOS 12 or later. This repository holds its downloads and nothing else.

The files are under [Releases](../../releases). Each release gives the size and SHA-256 of every file.

**On Windows**, extract the `.zip` first: the app does not run from inside it. The copies are not signed yet, so Windows and macOS ask once before opening one.
